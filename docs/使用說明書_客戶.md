# 使用說明書（給使用者）

正式站：<https://bill1114.github.io/ResourceSharingPlatform-Web/>

---

## 一、登入
1. 開啟網站，輸入**帳號**與**密碼**，按「登入」。
2. 忘記密碼或需要新帳號，請聯絡系統管理員。
3. 閒置過久可能被登出，重新登入即可。

## 二、看整體狀況（戰情總覽）
登入後首頁即為「戰情總覽」：
- 上方 4 張**彩色狀態卡**：據點低庫存、總量不足/啟動募資、即將過期、已過期。**點卡片**可進到該狀態的清單。
- 「各據點物資統計」表：狀態欄顯示各據點的低庫存/即將過期筆數；點「查看物資」看該據點物資清單。
- 「待處理需求」：顯示各據點「舉手」提出的缺料需求，可一鍵「轉移補貨」。

## 三、狀態清單與「舉手」求援
從戰情總覽點任一狀態卡進入清單：
- **缺料**（低庫存/即期/總量不足）：按「**舉手**」提出需求 → 需求方是你的據點、來源是物資所在的據點 → 送出後會出現在戰情總覽「待處理需求」，可接著做轉移補貨。
- **已過期**：操作改為「**報廢**」，直接帶你到報廢頁（限總管/據點管理人員）。

## 四、物資管理
選單「**物資管理 ▾ → 物資清單**」：
- 「篩選條件」：關鍵字、**狀態**（低庫存/即將即期/總量不足/已過期）、據點、種類，或用分類快切。
- 「依物資統計」：跨據點加總各品項總量與最近效期。
- 每列「操作」：👁 詳細、✏️ 編輯、⇄ 轉移、🗑 刪除（總管）。點**照片縮圖**放大並可「下載（中文檔名）」。
- 右上「**匯出 Excel**」：匯出目前篩選結果。

## 五、物資入庫（新增庫存）
「物資管理 ▾ → **物資入庫**」：
1. 選所在據點（預設你的據點）。
2. 填**品項**：選分類 → 物資種類 → 名稱 → 規格；填數量、有效期限（點欄位會跳出**日曆**挑日期）、（可）圖片。
   - **規格**若不確定，可選「**無（未指定）**」先入庫，之後由總管到「庫存種類設定」新增規格，再回物資清單「編輯」補上分類。
   - **一次多筆**：同一位捐贈人捐好幾樣時，按「**＋ 新增品項**」再加一筆（品項 2／3／4…），每筆各自選種類/數量/效期；要刪就按該筆右上「移除」。
3. （可）填**捐贈人**姓名/電話/地址 — 一次套用到本次全部品項；沒填也沒關係，之後可在「捐贈紀錄」補登。
4. 按「確認入庫」→ 跳出**確認視窗**核對**全部品項**與數量 → 按「確認入庫」一次完成入庫。

## 六、物資出庫 / 報廢
「物資管理 ▾ → 物資出庫 / 物資報廢」：
1. **出庫**：填領用人（姓名/聯絡/鄉鎮/身分別）→ 一項一項「新增物資」加入清單（可多品項）→ 送出前確認 →「確定出庫」。若發放後要回收，到「出庫紀錄」按「取消」即回庫。
2. **報廢**（總管/據點管理人員）：上方「即期/已過期」面板預設收合，點開可挑要報廢的批次；或從已過期清單的「報廢」帶入 → 填數量、原因 → 確認。

> 「物資捐贈」獨立頁已取消：捐贈人請在**物資入庫**時填；沒填的到「紀錄查詢 ▾ → 捐贈紀錄」補登/編輯/刪除。

## 七、跨據點轉移
「物資管理 ▾ → **物資轉移**」（總管/據點管理人員）：
1. 選來源、目標據點（不可相同）。
2. 「新增物資」挑批次（可看效期/現有）加入清單、填數量（可多筆）→ 送出前確認 →「確定轉移」，**立即扣掉來源庫存**。
3. 目標據點在「紀錄查詢 ▾ → 轉移紀錄」按「**確認送達**」才入庫；按「**取消**」退回來源。

## 八、AI 影像入庫
「物資管理 ▾ → **AI 智慧入庫**」：
1. 選據點，輸入文字描述**或**上傳照片，按「開始辨識」。
2. 系統列出辨識結果，**逐項核對**品項/數量/效期。
3. 按「確認並正式入庫」→ 資料寫入庫存，照片會出現在物資清單。

## 九、紀錄查詢與分析
「**紀錄查詢 ▾**」：
- 出庫/捐贈/報廢/轉移/AI 辨識**紀錄**，各頁可篩選、匯出 Excel。
- **捐贈紀錄**：列出各筆入庫，沒填捐贈人的顯示「待補登」，可按「補登/編輯」填捐贈人、或「刪除」該筆捐贈人紀錄（不影響庫存）。
- **領取分析**：以使用人/身分別/鄉鎮/品項多角度樞紐分析。
- **捐贈分析**：以捐贈人統計，展開可看「捐了什麼」與「這些物資後來發放給誰」（物流追蹤）。

## 十、物資明細（總管）
「**系統管理 ▾ → 物資明細**」：每筆物資從入庫到後續 出庫/捐贈/報廢/轉移/調整 的完整異動歷程。
- 可用 關鍵字/類型/據點 篩選、右上「匯出 Excel」匯出全部。
- 「**調整**」：盤點修正某批次目前數量（會留一筆調整紀錄）；「刪除」只對調整那種列開放，會把當初增減回算回去。

## 十一、常見問題
- **看到舊畫面？** 按 `Ctrl + F5` 強制重新整理。
- **圖片下載檔名是中文嗎？** 是，點縮圖放大後用「下載」按鈕，存下的就是中文檔名。
- **手機/LINE 使用**：從 LINE 圖文選單開啟功能，第一次會要求登入，之後直接進入。
