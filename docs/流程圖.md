# 流程圖（Flow）

> 以 Mermaid 繪製，GitHub / 支援 Mermaid 的 Markdown 檢視器可直接看圖。

## 1. 登入與權限守門

```mermaid
flowchart TD
    A[開啟任一網址] --> B{已登入?}
    B -- 否 --> C[導向 /login<br/>記住原路徑]
    C --> D[輸入帳號密碼]
    D --> E[帳號轉 {帳號}@local.invalid<br/>Supabase Auth 驗證]
    E -- 失敗 --> D
    E -- 成功 --> F[讀 profiles 取角色/據點]
    F --> G[導回原本要去的頁面]
    B -- 是 --> H{RoleGate 角色符合?}
    H -- 否 --> I[無權限畫面 / 隱藏]
    H -- 是 --> J[顯示功能]
```

## 2. 物資出庫

```mermaid
flowchart TD
    A[出庫頁：選據點→分類→物資批次] --> B[填數量/領用人]
    B --> C[invoke outbound-create]
    C --> D{Edge Function 驗證<br/>角色/據點/庫存足夠}
    D -- 不通過 --> E[顯示中文錯誤]
    D -- 通過 --> F[rpc outbound_create<br/>交易內扣量+寫紀錄]
    F --> G[（可）觸發 line-notify]
    F --> H[導回 /outbound + 成功訊息]
```

## 3. 跨據點轉移（狀態機）

```mermaid
stateDiagram-v2
    [*] --> Pending: transfer-create<br/>(立即扣來源庫存)
    Pending --> Confirmed: transfer-confirm<br/>(目的地加量/合併批次)
    Pending --> Cancelled: transfer-cancel<br/>(退回來源庫存)
    Confirmed --> [*]
    Cancelled --> [*]
```

## 3b. 缺料舉手 → 轉移補貨

```mermaid
flowchart TD
    A[戰情總覽點狀態卡→狀態清單] --> B{狀態?}
    B -- 已過期 --> R[報廢：帶批次進報廢頁]
    B -- 缺料(低庫存/即期/總量不足) --> C[按「舉手」]
    C --> D[需求方=登入據點<br/>來源=物資所在據點]
    D --> E[寫入 supply_request (Open)]
    E --> F[戰情總覽「待處理需求」顯示]
    F --> G[按「轉移補貨」→ 轉移頁 ?requestId=<br/>自動帶好來源/目標/品項]
    G --> H[完成→標記 Fulfilled / 取消→Cancelled]
```

## 3c. 盤點調整（物資明細）

```mermaid
flowchart TD
    A[物資明細某列按「調整」] --> B[填調整後數量+原因]
    B --> C[rpc stock_adjust<br/>改 supply_item.quantity + 寫 supply_adjustment_log]
    C --> D[明細新增一筆「調整」列]
    D -- 刪除該調整列 --> E[rpc stock_adjust_delete<br/>回算庫存 + 刪紀錄]
```

## 4. AI 影像入庫

```mermaid
flowchart TD
    A[上傳照片→ai-stockin bucket] --> B[invoke ai-stockin-recognize]
    B --> C[呼叫 Vision AI 辨識]
    C --> D[目錄比對/同義詞對照]
    D --> E[寫入 ai_stock_in_log<br/>狀態=待確認]
    E --> F[人工核對品項/數量/效期]
    F --> G[invoke ai-stockin-confirm]
    G --> H[rpc ai_stockin_confirm<br/>合併/新建 supply_item]
    H --> I[前端把照片搬到 items<br/>掛上 image_path]
    I --> J[導回物資清單 + 成功訊息]
```

## 5. LINE 通知（被動式）

```mermaid
flowchart TD
    A[出庫/捐贈/報廢/轉移/AI入庫 成功] --> B[內部呼叫 line-notify]
    B --> C[重算低庫存/即期/過期清單]
    C --> D[計算內容簽章]
    D --> E{與 notification_state<br/>上次簽章相同?}
    E -- 相同 --> F[略過，不重複發送]
    E -- 不同 --> G[推播給已綁定且開啟通知的帳號]
    G --> H[更新簽章]
```

## 6. LINE 帳號綁定

```mermaid
flowchart TD
    A[帳號管理→產生綁定碼] --> B[顯示 6 位數字碼]
    B --> C[使用者加官方帳號好友]
    C --> D[傳「綁定 XXXXXX」給官方帳號]
    D --> E[line-webhook 驗證簽章]
    E --> F[比對 line_bind_codes]
    F --> G[寫入 line_bindings<br/>綁定完成]
```

## 7. 手機頁面 / LINE 圖文選單串接

```mermaid
flowchart LR
    RM["LINE 圖文選單按鈕"] -->|URI| U["/#/mobile/inventory 等"]
    U --> P{已登入?}
    P -- 否 --> L[登入頁 → 登入後回到該功能]
    P -- 是 --> R{角色可用?}
    R -- 否 --> N[無法使用此功能]
    R -- 是 --> S[全螢幕手機功能畫面]
```

## 8. 發布流程

```mermaid
flowchart LR
    A[dev 開發+測試] --> B[建立 backup-main-* 回復點]
    B --> C[合併 dev → main]
    C --> D[GitHub Actions 自動部署]
    D --> E[正式站更新]
    A -.需要時.-> F[SQL Editor 跑 migration]
    A -.需要時.-> G[Dashboard 部署 Edge Function]
```
