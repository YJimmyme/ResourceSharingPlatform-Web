# 各模組說明

每個模組列出：功能、主要前端檔案、後端接點、權限。

## 戰情總覽（Dashboard）
- 4 張**可點擊**的狀態色卡（據點低庫存／總量不足·啟動募資／即將過期／已過期），點入對應「狀態清單」頁。
- **全域一致**：卡片數字與各據點狀態表改讀 `dashboard_summary` / `dashboard_location_status`（SECURITY DEFINER、只回統計數字），**全部角色都看到全部據點的真實狀態**（不再受「非總管只看自己據點」RLS 影響）。「查看物資」深連結僅總管顯示。
- 「待處理需求」面板：列出各據點「舉手」提出的缺料需求，可一鍵「轉移補貨」或標記完成/取消。
- 檔案：`pages/Dashboard.tsx`、`lib/statusColors.ts`
- 後端：`dashboard_summary`、`dashboard_location_status`、`supply_location`、`supply_request`
- 權限：全部登入者（皆看全域）

## 狀態清單（StatusList）
- 戰情總覽色卡點入後的清單頁（`/status/低庫存|總量不足|即期|已過期`）。全角色皆看全部據點（`supply_item` 讀取已放寬為全域）。
- 缺料（低庫存/即期/總量不足）可「**舉手**」提出需求（送總管審核的請求類功能）；「**已過期**」總管直接「報廢」、幫主「申請報廢」（舉手），小幫手無操作。舉手/申請報廢＝**總管＋幫主**可用、小幫手無。
- 直接操作類（如物資明細「調整」）另在各頁鎖自己據點；請求類（舉手/申請報廢）不鎖。
- 檔案：`pages/StatusList.tsx`；後端：`supply_item`、`global_low_stock_view`、`supply_request`

## 物資管理（物資清單）
- 篩選（關鍵字/**狀態**/據點/種類 + 分類快切）、跨據點統計、每列操作：**詳細資料 / 編輯 / 物資轉移 / 刪除**、照片點擊放大預覽（內含中文下載）、**匯出 Excel（底部含總計）**。
- 狀態篩選（低庫存/即將即期/總量不足/已過期）與低庫存判斷皆走 `lib/lowStock`（單一來源）。
- **安全庫存＝據點門檻**：清單/詳情/匯出的「安全庫存」直接顯示 `location_inventory_safety_stock`（庫存種類設定→據點門檻），編輯視窗此欄**唯讀**、不可改；來源統一，避免與低庫存判斷不同步。
- **檢視全域、操作限自己據點**：全角色皆可經戰情總覽「查看物資」開啟本頁（`/supply-items` 開放所有登入者）；小幫手唯讀（詳細/匯出），幫主可操作**自己據點**（詳細/編輯/轉移/刪除/入庫）、別據點唯讀，總管不限。選單「物資清單」仍僅總管。
- 檔案：`pages/SupplyItems.tsx`、`lib/lowStock.ts`、`lib/imageUpload.ts`、`lib/excelExport.ts`
- 後端：`supply_item`（直接 CRUD，RLS：讀全域、寫限縮）、`location_inventory_safety_stock`、`location_low_stock_view`、`global_low_stock_view`
- 權限：詳細=全部；編輯/轉移/刪除/入庫=總管（不限）或幫主（限自己據點）；小幫手唯讀。匯出=全部。

## 物資入庫（StockIn）
- 三步驟：所在據點（預設帳號所屬據點，總管可切換）→物資資訊→捐贈人資訊（姓名/電話/地址，皆可先留白）。
- **一次多品項**：步驟二是可重複的「品項 1／2／3…」清單（「＋新增品項」加一筆、「移除」刪一筆，至少保留一筆），每筆各自有分類/種類/名稱/規格/數量/效期/圖片；據點與捐贈人為共用，一次套用到全部品項（對應「同一捐贈人多筆」）。
- **規格可選「無（未指定）」**先入庫，之後由總管在庫存種類設定新增規格、再到物資清單「編輯」補上（寫回 `specification`＋`inventory_item_variant_id`）。
- 有效期限用 `DateSelect`（原生 `<input type=date>` 日曆，min/max 限制合理年份）。
- 送出前跳「確認入庫」視窗核對**全部品項**與數量。確認後**單次批次** insert 建立所有 `supply_item`，再批次寫入對應 `supply_stock_in_log`（可後補的入庫來源紀錄，補登資料不會再次增加庫存）。
- 檔案：`pages/StockIn.tsx`、`components/SupplyItemForm.tsx`、`components/ConfirmActionModal.tsx`、`components/DateSelect.tsx`（`SupplyItemForm` 已改為一次載入 definition/variant 於各品項本地連動，不再逐筆呼叫 `useCascadingCatalog`）
- 後端：`supply_item` 批次 insert、`supply_stock_in_log` 批次 insert；圖片上傳 `items` bucket

## 出庫 / 報廢（Create）
- **出庫**：批次（一位領用人一次多品項）＋領用人分局/鄉鎮/身分別；送出前確認視窗；出庫紀錄可「取消（回庫）」退回原批次。
- **報廢**：挑既有批次（即期/已過期面板預設收合），送出前確認視窗；已過期清單可帶 `?supplyItemId=` 直接進來。
- 共用 `StockBatchPicker` / `OutboundModals` / `ConfirmActionModal`。
- 檔案：`pages/SupplyOutbound.tsx` / `SupplyDisposal.tsx`
- 後端：`outbound-create`（單筆）/`outbound_create_batch`（批次）/`outbound-cancel`（回庫）/`disposal-create`
- 權限：出庫=全部；報廢=總管/據點管理人員

## 捐贈紀錄（SupplyDonation）
- 「物資捐贈」獨立頁**已移除**：捐贈人統一在物資入庫時填。此頁讀入庫來源紀錄（`supply_stock_in_log`），可依「已填/待補登」篩選，對每筆**補登/編輯**捐贈人（姓名/電話/地址）或**刪除**（只動來源紀錄、不影響庫存）。
- 檔案：`pages/SupplyDonation.tsx`；後端：`supply_stock_in_log`、`donor_leaderboard_view`

## 物資轉移（Transfer）
- 與出庫相同概念的批次版型（步驟卡＋物資挑選視窗＋送出確認）；多品項一次轉移、狀態機（建立/確認/取消）。
- 物資清單「轉移」按鈕帶 `?supplyItemId=`、戰情總覽「轉移補貨」帶 `?requestId=` 預帶。
- 檔案：`pages/SupplyTransfer.tsx`、`components/OutboundModals.tsx`、`components/ConfirmActionModal.tsx`
- 後端：`transfer-create` / `transfer-confirm` / `transfer-cancel`
- 權限：總管/據點管理人員

## 物資明細（ItemLedger）
- 「一列一筆異動」的完整明細：每筆物資的 入庫/捐贈/出庫/報廢/轉移/調整 各攤一列，顯示 類型/增減數量/說明/目前數量（依時間累加）；可用 關鍵字/類型/據點/日期區間 篩選、匯出全部（底部含總計）。
- 「**調整**」＝盤點修正該批次目前數量（`stock_adjust`）；「**刪除**」只對「調整」列開放並回算（`stock_adjust_delete`）。
- **權限**：總管看全部據點並可調整；**幫主只看自己據點**的明細並可調整（看不到別據點，據點篩選唯讀顯示自己據點）。小幫手無此頁。
- 檔案：`pages/ItemLedger.tsx`；後端：各異動紀錄表 + `supply_adjustment_log`、`stock_adjust` / `stock_adjust_delete` RPC

## 操作紀錄（ActivityLog，稽核 Log，總管專用）
- 集中式稽核：記錄 誰／何時／做了什麼（分類：登入／庫存異動／資料維護／申請）。各操作成功後由前端 `logActivity()` 寫入 `activity_log`；登入登出於 `useAuth` 記錄。
- 可依 關鍵字／分類／據點／日期區間 篩選、看細節（含 detail JSON）、匯出 Excel。
- 檔案：`pages/ActivityLog.tsx`、`lib/activityLog.ts`；後端：`activity_log`（RLS：檢視限總管、寫入限本人）。路由 `/admin/activity-log`。

## AI 影像入庫（AIStockIn）
- 文字或照片辨識 → 待確認 → 人工核對 → 正式入庫；辨識紀錄頁。
- 檔案：`pages/AIStockIn.tsx`、`lib/functionError.ts`、`lib/imageUpload.ts`
- 後端：`ai-stockin-recognize` / `ai-stockin-confirm`；`ai_stock_in_settings`、`catalog_synonym`

## 領取分析（RecipientAnalysis）
- 樞紐（pivot）分析：以「使用人/身分別/鄉鎮別/物資品項」為分析角度＋明細維度，多值篩選（同類 OR、跨類 AND），可匯出。直接讀 `supply_outbound_log` 明細（排除已取消）。
- 檔案：`pages/RecipientAnalysis.tsx`、`components/AnalysisFilterModal.tsx`、`lib/analysisFilters.ts`

## 捐贈分析（DonorAnalysis）
- 以捐贈人為主軸的統計＋**物流追蹤**：展開每位捐贈人可看「捐了什麼」與「這些批次後續發放給誰」（批次層級近似），含地址/鄉鎮/身分別、可匯出。
- 捐贈人來源：`donation_source_view`（物資捐贈 + 物資入庫有捐贈人者的聯集）；流向靠 `supply_item_id` 對應 `supply_outbound_log`。
- 檔案：`pages/DonorAnalysis.tsx`；後端：`donation_source_view`、`supply_outbound_log`

## 分析中心（AnalyticsHub，總管專用）
- 總覽：各來源（領用/入庫/捐贈/報廢/轉移）在日期區間內的總量卡片。
- 自由選擇：**資料來源 × 分組維度**（據點/物資/種類/身分別/鄉鎮/報廢原因/月份，依來源提供）**× 呈現方式**（長條/圓餅/表格）**× 日期區間**；可匯出目前分析（含總計）。
- 圖表以內建 CSS 長條與 SVG 圓餅呈現（不加相依、GitHub Pages 相容）。第一版，之後可擴充維度/交叉分析。
- 檔案：`pages/AnalyticsHub.tsx`；後端：各異動 log 表 + `supply_item`/`supply_location`。路由 `/analytics`。

## 登入與忘記密碼（Login）
- 帳號登入（帳號→合成 email 轉給 Supabase Auth）；登入後統一導向戰情總覽（保留 `/mobile/*` 深連結）。
- **忘記密碼（自助重設）**：輸入帳號＋新密碼（≥6 碼）即立即重設，經 Edge Function `password-self-reset`（service role）改密碼並在 `profiles.password_changed_at` 蓋時間戳；總管在帳號管理看到「近 7 天曾自助改密碼」須注意名單。
- 檔案：`pages/Login.tsx`；後端：Edge Function `password-self-reset`、`profiles`。

## 據點管理（SupplyLocations）
- 據點 CRUD、篩選（關鍵字/座標狀態/聯絡資訊）。檔案：`pages/SupplyLocations.tsx`；後端：`supply_location`（RLS：Admin 寫）

## 庫存種類設定（InventoryTypes）
- 目錄定義、規格、各據點安全庫存門檻；**全系統安全總量依規格分開設定**：募資觸發點＝**門檻 × 0.9**（當全據點加總 < 門檻×0.9 列為總量不足/啟動募資）。停用的種類／規格皆可重新啟用。
- **自訂排序**：列表可**拖拉**調整顯示順序（寫入 `inventory_item_definition.sort_order`；僅在未套用篩選時開放拖拉）。
- 檔案：`pages/InventoryTypes.tsx`；後端：`inventory_item_definition`、`inventory_item_variant`（`global_safety_stock`、`global_threshold`）、`location_inventory_safety_stock`

## 帳號管理（AccountManagement）
- 新增帳號（彈窗）、編輯、停用（刪除）、LINE 綁定碼/解除。檔案：`pages/AccountManagement.tsx`；後端：`account-admin`（防呆：不能停最後一個 Admin/自己）

## 系統設定（AdminSettings）
- LINE 通知設定、AI 智慧入庫設定（金鑰於此輸入，存資料庫）。檔案：`pages/AdminSettings.tsx`；後端：`admin-settings`

## 手機頁面（MobileFeatures）
- 全螢幕：物資查詢 / 物資領用 / 物資轉讓 / 影像入庫，供 LINE 圖文選單串接；工程模式啟動器可預覽。
- 檔案：`pages/MobileFeatures.tsx`、`pages/mobile-original.css`
- 網址：`/mobile/inventory|pickup|transfer|vision`
