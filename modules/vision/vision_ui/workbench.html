建議事項
    各品項資料與表現
    精確率：模型框出的物件有多少是對的；召回率：實際物件有多少被找到。數值來自上線模型最近一次保留集評估。複核門檻為發布時依評估校準的值，信心低於此值的框會交由雲端複核。
    主系統整合
    此模組負責照片標註、YOLO 辨識及建模。主系統負責登入與庫存，透過 API 呼叫辨識服務。不確定時由整合層交給 OpenAI 複核。
    標註類別對應主系統品項 ID
    名稱可調整，品項 ID 應保持固定。未對應的類別會回傳 itemId=null，交由整合層核對。
    API 範例
    POST /api/v1/predict
{"image":"data:image/png;base64,...","model":"pretrained","confidence":0.25}

回傳：apiVersion、model、objects、counts
objects 的每筆包含 itemId、label、bbox、confidence。
bbox 為左、上、右、下，座標範圍 0 到 1。

正式整合：POST /vision-api/api/v1/recognize
傳入登入憑證、據點與本人上傳的照片路徑，執行 YOLO / OpenAI 混合辨識。
本機獨立模式不提供 /recognize，不會寫入庫存。
