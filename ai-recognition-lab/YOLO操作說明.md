# YOLO 本機辨識、標註與專屬訓練

開啟 http://127.0.0.1:5180/yolo 。從「啟動測試.cmd」啟動，會同時啟動 YOLO 本機服務（5181）。YOLO 不需要 OpenAI API Key。此電腦已安裝獨立 `.venv-yolo` 環境與 YOLO11n 預訓練權重，目前使用 CPU；GPU 選項須另外具备相容 CUDA 的 PyTorch。

## 第一次使用

1. 新增你要識別的品項，例如「杯裝泡麵」「瓶裝水」「箱裝水」。品項名稱與ID保持穩定，不按品牌細分。
2. 上傳照片，可以直接手動畫框，也可以按 YOLO 辨識。通用模型的80類不等於你的目錄，可能只識別 bottle、cup；請改成專屬品項。
3. 「新增框」時按住滑鼠拖曳；「選取／移動框」時拖曳框可移動，拖右下角可改大小。逐列更改類別或刪除誤判框，補上漏掉的物品。每個可見外包裝一個框，一箱水就是一箱，不猜裡面的瓶數。
4. 選訓練、驗證或保留測試集。相似照片與同一批連拍填相同群組，必須分在同一集合。建議依拍攝批次安排約70%訓練、15%驗證、15%測試，不以同場景隨機分割。
5. 全部核對後勾選人工核對完成，按保存。空場景需額外勾選負樣本。未人工核對的AI框不能直接成為訓練資料。

## 辨識錯誤時

上傳原始照片 → 修正框、品項 → 寫下錯誤原因 → 保存到訓練集合。保存並不即時訓練；累積一批不同角度、距離、光線與背景的案例後再訓練。正確案例也要保留，避免只學錯誤照片。單純「泡麵3杯」無法取代3個逐物件框。

已保存資料可從清單重新載入修改；歷史版本保留在 history。相同像素的圖片會視為同一張，不會跨集合重複保存。重新拍攝或壓縮的相似圖仍需自行用群組管理。集合和群組一旦保存就固定。

## 訓練

第一次選「YOLO11n 通用預訓練」，設定30輪，CPU，按開始訓練。至少要有有框的訓練與驗證資料；一兩張只能驗證流程，不能證明泛化能力。程式會先建立不可變資料快照，使用 batch=2、imgsz=640、固定seed與workers=0。少量訓練不保證變準。

完成後重新整理模型清單，選新專屬模型進行辨識。後續可選舊專屬模型作起點微調，使用含舊樣本與新標註的完整資料集。類別增加時需重新檢查模型效果。

「評估保留測試集」會用所選模型，門檻0.15（`modules/vision/config/vision.yaml` 的 evaluation.confidence），計算每張照片的品項及數量完全正確比例，以及每張照片的數量絕對誤差總和的平均；另外列出各品項精確率／召回率與門檻校準。啟用模型前須與目前上線模型在同一份保留集比較不退步，詳見 `modules/vision/README.md`。訓練中的 mAP 來自驗證集，與數量完全正確率不同。不同模型應用相同保留集比較，避免調整時反覆依測試集答案修模型；需要時另建新拍攝批次做最終評估。

每次訓練/評估保存 config、state、console.log 與資料快照，訓練權重在 runs/<工作ID>/train/weights/best.pt；評估明細在 evaluation.json。可按停止，已保存資料不會刪除。重啟服務後可重新選取已完成權重。

## 匯出與備份

匯出ZIP含 images/train、val、test，對應 labels/*.txt，以及 data.yaml、manifest.json。每行標註為 class_id center_x center_y width height，座標0至1。data.yaml 是JSON格式的合法YAML；將ZIP解壓後，把path改成解壓資料夾的絕對路徑再交給其他訓練環境。

照片、標註、歷史、資料快照與模型都放本機 `ai-recognition-lab/yolo-data/`，請備份整個資料夾。此目錄與模型/虛擬環境已排除版本控制。沒有自動上傳照片到雲端。

離線測試：`.venv-yolo\Scripts\python.exe -m unittest test_yolo_data.py`。新電腦執行「安裝YOLO.cmd」，首次辨識需要網路下載官方預訓練權重。

使用Ultralytics套件與權重；後续正式散布或商用整合請依其AGPL-3.0／Enterprise授權條件處理：https://www.ultralytics.com/license 。此工具的本機標註與訓練尚不會更新正式Supabase入庫流程。


## 只有一張照片：練習模式

先將照片框選、核對並保存為 train。在「3. 訓練與評估」勾選「單張照片練習模式」，從練習照片選單選該照片，選 CPU 後開始訓練。勾選時預設改為1輪。此模式只取選定的一張有框訓練照片，不更動原本的資料集合。YOLO內部最後可能對同張照片做檢查，這些分數不能當成獨立驗證準確率。完成後模型選單顯示「練習模型（無獨立驗證）」，可以選來辨識圖片，但不能發布到正式系統。一般訓練仍要求獨立 train 和 val，另有 test 時可取消練習勾選後進行保留集評估。
